## 〇、版本 / 语体层（本轮修复，2026-10-26）

全站 8 版本原标「繁 / 简 / 白」三语体，实际核对发现三处硬伤，已修复：

1. **繁体层名不副实** — 除 `jin70`（金批繁）外，其余 7 版本的 `fan/` 目录里装的是**简体文本**（繁体字数为 0），且多数回与 `jian/` 逐字节相同。
   - 已用 OpenCC `s2t` 对 **575 个 fan 文件**重新生成真繁体；`fan`（繁）与 `jian`（简）现已真正分离。
2. **白话层是带伤的机械替换** — 原 `build/rebuild_jian_bai.py` 用朴素 `str.replace` 链，规则表含大量单字替换（`并→和`、`之→的`、`皆→都`、`即→就`、`便→就`），且诗词保护只认以「诗曰」开头的行。
   - 后果：诗句被改（「尚衣」→「还衣」、「皆敛迹」→「都敛迹」）；生成病句（「谓之」→「对……说的」、「约莫」→「约别」、「并无」→「和无」、「不见」→「不看见」、「已后」→「已经后」、「即便」→「就就」）。
   - 已重写为 `build/rebuild_bai_v2.py`：**韵文/駢文整块保护**（对仗短句判定）+ **最长匹配单遍替换** + **叠字回缩**，重建 **646 个白话文件**。
   - 复核：行数对齐 646/646、韵文被改 0 行、规则碰撞叠字 0 处。
3. **版本间正文未区分** — `v120`（袁百二）有 **91/101 回**与 `v100`（容百回）逐字节相同，仅第 91-100 回不同；`v70`/`jin70_pi`/`jinshengtan` 三版同文。
   - 底本同源可解释金批系三版同文；但袁本未体现异文，属**数据源限制**，需另找袁本异文校勘本才能补，已列入下方待办。
4. **阅读器默认定位** — 原默认 `ch=1`，会跳过每版首条（如 v120 的「引首」、zsk 的第 82 回）；已改为从首条开始。
5. **jiqin（冀勤校注）** — 其「正文」内嵌 `(N)` 注号与「词语——释义」体例（101 回全部如此），属该书整理体例，暂保留原貌；若要拆分为「干净正文 + 分层校注」需另作工程。

> 说明：白话层现为**保守词汇现代化**（韵文原样、散文做安全词替），**并非逐回文学性重述**。要达到「真正的现代汉语翻译」需对约 400+ 回逐回重写，属大批量作业，见第三节第 9 项。

- **现状**：已完成《新评水浒传叙》全文 +《命名释义》10 则（水浒/史进/鲁达/宋江/柴进/李逵/关胜/卢俊义/高俅/殷天锡）

### 4. 当代会评本（参考校核层，不平行入库）

- **处理方式**：
  - 可据原刻本录批语，不直接转录现代整理本的评语汇编
  - 作为**校核参照**：用于校验余评/钟批/王评等旧批录入的错字、断句
  - 当代评论文章、论文观点以"研究文献"节点入知识图谱，不做正文批注层
