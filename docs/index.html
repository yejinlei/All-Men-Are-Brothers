PROLOGUE

一部书的千古忠义

《水浒传》起自洪太尉误走妖魔，终于宋公明神聚蓼儿洼，一部大书记一百单八人之聚散死生。其书以"忠义"二字为眼，以"乱自上作"四字为骨：乱由上作、忠被奸误、义聚山林、魂归水泊，是为千古悲剧。

本站以本体论（Ontology）方法系统建构水浒世界——版本、人物、关系、事件、地点、兵器、评点、衍生——从繁本简本的版本文献，到鲁智深武松的豪侠气骨，从梁山泊蓼儿洼的地理空间，到金圣叹、李卓吾、胡适、鲁迅的千年评说，一一纳入结构化知识框架。

八方共域，异姓一家。相貌语言，南北东西虽各别；心情肝胆，忠诚信义并无差——此水浒之所以为天下第一快书也。

🔗 派系归属推理

规则：若人物P与派系核心人物C为"结义/心腹/恩义"关系，且P上山地属于C的聚义事件，则推导P派系归属与C一致。
例：李逵与宋江（江州死士）→ 推导李逵属江州系/宋江嫡系。

📈 版本演化推导

规则：版本A有"楔子+惊恶梦"、无招安内容、有金氏评语 → A为金圣叹系统；版本A征田虎王庆20回齐全且有袁无涯序 → A属袁无涯百二十回本系。

💀 命运结局推导

规则：招安路线核心推动者（宋江/吴用等）→ 悲剧结局概率极高；二龙山反招安派（鲁智深/武松/燕青等）→ 功成身退/坐化/出家概率高；特技人才（安道全/皇甫端/乐和）→ 战前被朝廷留下概率高。
