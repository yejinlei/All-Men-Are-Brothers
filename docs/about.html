关于本站

本站是一个以《水浒传》为对象的数字人文研究与教学平台：在八版本三语体语料（共 1938 回文件）之上，叠加九家评点批注、本体知识库与若干可计算分析产物，目标是把小说从"文本"升级为「可计算的研究对象 + 可演示的教学平台」。

一、站点定位

  • 不是电子书：不以"读完一本书"为目标，所有页面都围绕"比对、检索、计量、可视化"设计。
  • 不是定论：Step 4（情感曲线）、Step 7（文体计量）等结果都是可计算假设，页面会明写方法与不确定性，不替代学者判断。
  • 可扩展：版本与批注元数据集中于 data/registry.json（单一可信源），新增一个版本只需补语料目录 + 在注册表加一行，无需改动 HTML/JS。
  • 全静态：站点托管于 GitHub Pages，无后端，所有计算要么在构建期（build/*.py）离线完成、要么在浏览器里即时运行（阅读器对照、TEI 导出、小游戏）。

二、技术栈

前端

  • 纯静态 HTML/CSS/原生 JS（无构建依赖）
  • ECharts 5 本地 vendored（vendor/echarts.min.js，离线可用）
  • 站点配色统一：朱砂 #9e2b25、靛青 #2e5a88、米黄底 #f7f2e7

构建与分析

  • Python 3：numpy / scipy / scikit-learn / networkx / matplotlib
  • 中文处理：jieba 分词、pypinyin 声调判平仄、opencc 简繁转换
  • 所有脚本在 build/，可复现（见 build/README.md）

本体建模（OWL2 DL 思路）

  • 7 大顶级类（人物／地点／事件／组织／物品／作品／评点）
  • 18 类有向关系，边自带"首次出现回目"
  • 三重数据校验（实体唯一/回次范围/版本隔离）

数据托管

  • GitHub Pages：yejinlei.github.io/All-Men-Are-Brothers
  • 正文与批语均随仓库发布
  • 数据版本号见 数据开放 页

三、方法与不确定性说明（重要）

  • 情感曲线：使用自建情感词典（正负词+激烈度），按段落打分、按回聚合、滑动平滑。词典规模有限（约 2000 词），峰值识别对词典敏感；金批腰斩本结局的"惊恶梦"情感落差仅在金批七十回系统下可观察。
  • 人物网络：关系抽取自公开水浒本体与回目/正文共现规则，不做 NER 训练；"结拜/亲属/师徒"较准，"上下级/从属"依赖职务表；删点实验只反映图结构层面的连通性，不等同于文学意义上的"人物重要性"。
  • 文体计量：采用高频虚词频率 + 字符 3-gram 两种口径；田虎王庆段"不合群"是统计上可观察的差异，与"后人增插"的学术假说方向一致，但不直接证明作者不同——样本量、用字习惯（地名/官名差异）都会影响结果。
  • 回目格律：平仄以普通话四声判定（pypinyin），不能识别中古入声，故"上仄下平率 0.40"是今音近似值；对仗只做字数相等、重字比对等浅层指标，未做词性对品。
  • 版本谱系：对齐回次时已处理金批本的 OFFSET=−1（以故事回次而非文件回次为锚），但 v120 前 90 回与 v100 的"距离≈0"不代表完全相同，仍有大量细节异文。
  • 批注可信度：分为 A/B/C/D 四级（见 数据开放），B 级以下批语可能含 OCR 讹字、回次偏移或出自二次文献，引用前请回查原刻本。
