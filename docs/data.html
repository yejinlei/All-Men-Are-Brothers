按版本/回次/语体取正文

正文存放在 texts/versions/<vid>/<style>/chapter_NNN.json，其中 vid 取自注册表 versions[].id（v120/v100/v70/jin70/jin70_pi/jinshengtan/jiqin/zsk），style 取 fan/jian/bai（繁／简／白）。文件结构示例：

二、TEI XML 导出

为兼容学界 TEI（Text Encoding Initiative）工作流，提供以下批量导出按钮。TEI 用 <note type="commentary" resp="…" anchored="false"> 对齐批语、用 <l> 标记韵文、用 <seg type="baihua"> 标注白话层。

由于 GitHub Pages 是静态托管，以上按钮在浏览器端即时拼装 TEI 文件，大版本可能需要数秒。导出的 TEI 可直接在 TEI 兼容工具（如 oXygen、TEI Publisher）中打开。

三、引用本数据

建议引用格式（GB/T 7714）：

《水浒传》数字人文站点开发组. 水浒传·多版本数字人文 [DB/OL]. 数据版本 . (2026-10-27). https://yejinlei.github.io/All-Men-Are-Brothers/

单条批注引用示例：

[清]金圣叹. 第五才子书施耐庵水浒传·第二十三回回前批 [M]// 贯华堂原刻本, 明崇祯十四年(1641). 见：《水浒传》数字人文站点, read.html?vid=jin70_pi&ch=23（数据版本 ，可信度 A 级精校）.

四、使用规范

  • 非商业使用：教学、研究、二次开发可自由使用，注明本站链接与数据版本号即可。
  • 古本公版：正文（八版本繁/简）出自公领域古籍整理，金圣叹、李卓吾等明清评点亦属公版。
  • 白话层版权说明：白话文为站点自行生成的词汇现代化版本，采用 CC BY-NC-SA 4.0 协议，商业使用需联系作者。
  • 现代校注：冀勤校注为当代学者作品，摘录范围限于词典式释义（短句），如整书重印请使用正规出版社版本。
  • 数据缺口：可信度 B/C/D 级批注（机器 OCR 整理 / 二次文献转引 / 序跋总评）不可直接引用作定论，请回查原刻本；详见 路线图。
