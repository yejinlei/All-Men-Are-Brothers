# 《水浒传》白话层翻译规范（v120 及全版本通用）

> 目标：把 `docs/texts/versions/<ver>/jian/<ch>.txt`（简体原文）逐段翻译为
> `docs/texts/versions/<ver>/bai/<ch>.txt`（现代汉语白话文，简体）。
>
> ⚠️ 现状问题：此前的 bai 层是用一份词表做**正则替换**生成的（如 `但见→只见`、`次日→第二天`、
> `皆→都`、`方→才`），既保留了大量文言词汇与句式，又因单字盲替换产生病句（如
> `四方无事` 被替换成 `四才无事`）。这**不是翻译**。本次起全部改为逐段真翻译。

## 一、硬性规则（违反即不合格）

1. **逐段对应，结构一致**
   - 输出行数必须与 `jian` 源文**完全相同**；空行位置也必须相同。
   - 源文一般「一行 = 一个自然段 / 一句诗」，白话也一行一段，不得合并或拆分。
2. **韵文一律照抄，不改一字**
   - 凡 `诗曰` / `词曰` / `有诗为证` / `有词为证` / `正是` / `但见` / `只见` / `有分教` /
     `赞曰` / `偈曰` / `古风` 等**引领语之后**的诗、词、赋、骈句、赞语，原样保留（含标点）。
   - 回末「有分教：……且听下回分解」中的对句保留。
   - 原文中夹在叙述里的短对句（如「一条杆棒等身齐，打四百座军州都姓赵」）同样保留。
3. **专名保留原文用字**：人名、绰号、地名、官名、年号、书名、神号等一律照抄。
   - 例：宋江、洪信、太尉、参知政事、东京、汴梁、信州贵溪县、龙虎山、上清宫、
     嘉祐三年、嗣汉天师、虚靖天师、罗天大醮、紫宸殿、三清殿、伏魔之殿。
4. **其余正文必须真翻译**：把文言虚词与句式改写为现代汉语。
   - 禁止残留：`曰`（除「诗曰／词曰／赞曰」等引领语）、`矣`、`焉`、`汝`、`吾`、`哉`、`兮`。
   - 常见对应：`曰→说/道`、`汝→你`、`吾→我`、`岂→难道`、`莫不→莫非`、`即便→立刻`、
     `次日→第二天`、`目今/目下→如今/眼下`、`怎生→怎么`、`恁地/恁般→这样`、`端的→确实`、
     `一似→好像`、`缧绁之厄→牢狱之灾`。
   - 句式按现代汉语语序重组，对话口语化；「……得见」等文言句式改成「才能见到」这类现代说法。
5. **不增删、不解释**：不补情节、不加括号注、不做考据说明。
6. **篇幅**：白话约为原文的 1.05–1.60 倍（过长多半是掺了注释，过短多半没真翻译）。

## 二、质量自检（提交前自查）

- [ ] 行数与空行位置 = 源文
- [ ] 每一处韵文与源文**逐字一致**
- [ ] 正文中无 `曰/矣/焉/汝/吾/哉/兮`（引领语里的「诗曰/词曰」除外）
- [ ] 无病句（尤其警惕旧词表产物如「四才无事」）
- [ ] 专名与源文用字一致
